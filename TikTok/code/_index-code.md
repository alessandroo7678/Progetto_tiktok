# Indice — code

Script del cervello. Dalla cartella TikTok: `python3 code/genera_indici.py` rigenera gli indici, `python3 code/gate_qualita.py` controlla il cervello, `python3 code/genera_llms.py` rigenera il llms.txt di ogni cervello, `python3 code/genera_showcase.py` rigenera `_showcase/showcase.md`, `python3 code/perplexity.py "domanda" --recency day` cerca notizie sul web con Perplexity (chiave in `env/.env`). `python3 code/analizza_video.py` trascrive e scompone in fotogrammi i video di `sources/esempi-video/`.
